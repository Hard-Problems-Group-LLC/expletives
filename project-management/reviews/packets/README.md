# Review Packets

Store explicit draft packets and immutable, versioned frozen packets here.
Use:

```text
EXPL-REV-NNN-<topic>-<stage>-vN.md
```

A draft must say conspicuously that it is not frozen or reviewable. A frozen
packet follows the inventory, SHA-256 manifest, dirty-worktree, and addendum
rules in the
[`Panel Of Experts Charter`](../panel-of-experts-charter.md).
