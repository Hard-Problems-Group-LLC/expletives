# Review Decisions

Keep evidence-chair dispositions separate from operator decisions:

```text
EXPL-REV-NNN-<stage>-evidence.md
EXPL-REV-NNN-<stage>-operator.md
```

The evidence chair validates and classifies evidence but cannot approve,
defer, reject, or accept risk. Those actions require an explicit operator
record under the
[`Panel Of Experts Charter`](../panel-of-experts-charter.md).
