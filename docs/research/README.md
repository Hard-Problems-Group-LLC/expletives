# Research

This directory contains non-normative source reviews and transferable lessons
that inform proposals, specifications, and decisions.

Research documents are evidence, not implementation authorization. When the
project adopts or rejects a pattern, record the decision in
[`project-management/`](../../project-management/README.md) and update the
applicable specification.

## Current Reviews

- [`ui-toolkit-lessons.md`](ui-toolkit-lessons.md) compares relevant control,
  event-loop, threading, keyboard, rendering, and automation practices from
  established GUI and terminal UI toolkits.
